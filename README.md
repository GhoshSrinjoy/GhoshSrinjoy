## Research: RICHES

**RAG with Intelligent Cross-Document Clustering and Hybrid Ensemble Search**

For my master’s thesis, I designed and implemented a self-hosted, multimodal RAG system for secure document processing in English and German.

![Research and development animation](https://media.giphy.com/media/SWoSkN6DxTszqIKEqv/giphy.gif)

- **Local parsing:** Extracts text, tables, images, and mathematical equations using layout detection and specialized OCR, without VLM dependencies.
- **Hybrid retrieval:** Combines vector search, BM25, SQL metadata search, and image similarity through Reciprocal Rank Fusion.
- **Structured search:** Uses ingestion-time clustering and query strategies ranging from factual lookup to multi-step agentic planning.
- **Traceable answers:** Produces language-consistent responses with inline citations.

My thesis evaluation reported a **93.7% completion rate**, with the system operating within a **24 GB VRAM** budget.
